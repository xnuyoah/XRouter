# Provider logo assets

- `anysearch.png`: AnySearch official favicon, used because LobeHub has no icon.
- `tinyfish.svg`: Tinyfish official mark, used because LobeHub has no icon.

All other provider and search-channel marks come from
[`@lobehub/icons`](https://github.com/lobehub/lobe-icons) (MIT) and are imported
through their per-icon entry points to keep the single-file bundle small.
